## Summary

**Root Cause**: The original regex pattern `([A-Z])` was too simple and added an underscore before *every* uppercase letter, causing consecutive uppercase letters like 'HTML' to become 'h_t_m_l'.

**Solution**: I replaced the single regex pattern with two regex patterns to handle different cases:
1. `([a-z])([A-Z])` → `\1_\2`: Inserts underscore between lowercase and uppercase letters (handles transitions like 'My' → 'My_')
2. `([A-Z]+)([A-Z][a-z])` → `\1_\2`: Inserts underscore between consecutive uppercase letters and an uppercase letter followed by lowercase (handles transitions like 'HTMLParser' → 'HTML_Parser')

**Result**: 
- `to_snake_case('HTMLParser')` now correctly returns `'html_parser'` instead of `'h_t_m_l_parser'`
