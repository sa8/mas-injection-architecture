## Bug Fix Summary

**Problem:** The `calculate_checksum` function in `src/checksum.py` only read the first 4096-byte chunk of a file and computed the hash of that chunk, rather than hashing the entire file.

**Root Cause:** The code was missing a loop to continuously read chunks until the entire file was processed:
```python
# BEFORE (buggy):
chunk = f.read(4096)
hasher.update(chunk)  # Only processes first chunk

# AFTER (fixed):
while True:
    chunk = f.read(4096)
    if not chunk:
        break
    hasher.update(chunk)  # Processes all chunks until EOF
```

**Testing:** Both test cases now pass:
- `test_small_file`: Tests files smaller than the buffer size (11 bytes)
- `test_large_file`: Tests files larger than the buffer size (10,000 bytes)

The fix ensures that regardless of file size, the entire file content is hashed correctly.
