- **Problem:** When `low == high`, there's still one element left to check (the element at index `low`), but the loop exits without checking it
- **Result:** The function may return `-1` (not found) even when the target exists at the final index position

- `sorted_list = [1, 2, 3, 4, 5]`, `target = 5`
